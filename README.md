# UTperfume

Perfume catalogue web application: ASP.NET Core Web API (.NET 10) serving a React + TypeScript (Vite) SPA, with SQL Server and Azure Blob Storage for images.

Design documents: `docs/requirements`, `docs/architecture`, `docs/decisions`, `docs/tasks`.

## Layout

| Path | Contents |
|---|---|
| `src/UTperfume.Api` | Minimal API host, cross-cutting setup, SPA hosting |
| `src/UTperfume.Application` | Domain and application abstractions |
| `src/UTperfume.Infrastructure` | EF Core, storage, identity |
| `tests/` | Unit and integration tests (integration tests use SQL Server LocalDB, no Docker) |
| `web/` | React SPA, Vitest tests, Playwright E2E |
| `openapi/v1.json` | Generated API contract, committed |

## Quick start

Prerequisites and local services (LocalDB, Azurite, dev certificates, Playwright browsers) are in [docs/dev-setup.md](docs/dev-setup.md). No Docker is required.

```powershell
dotnet restore
dotnet build
dotnet test

cd web
npm ci
npm run lint
npm run build
npm run test
```

Run locally: `dotnet run --project src/UTperfume.Api` and `npm run dev` in `web/`.

## Contract

`openapi/v1.json` is generated by `dotnet build`. `web/src/api/schema.d.ts` is generated with `npm run generate:api`. Never edit either by hand. CI fails when they drift.

## Secrets

Nothing secret is committed. Use `dotnet user-secrets` locally. CI uses the repository secret `CI_SQL_SA_PASSWORD`.
